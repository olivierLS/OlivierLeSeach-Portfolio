Case study

Deployment and standardisation

Standardising and securing DSDEN 56 workstations through an automated deployment workflow.

  • MDT / WDS
  • WAPT
  • PowerShell
  • Clonezilla
  • User support

Context and goals

The workstation fleet was heterogeneous, which created instability, recurring incidents and longer preparation times. The goal was to deliver ready-to-use, secure and consistent environments.

Technical solutions

Use of WDS and MDT for network-based Windows installation.

Application deployment with WAPT and automation through PowerShell scripts.

SSD preparation and cloning with Clonezilla, followed by user data migration.

Main stages

  1. Analyse the hardware and software environment.
  2. Prepare the deployment server and naming conventions.
  3. Test on a first workstation batch and adjust scripts.
  4. Deploy at scale while transferring user data carefully.
  5. Write a step-by-step technical guide for future deployments.

Benefits and results

  • More stable and consistent user environments.
  • Shorter workstation preparation times.
  • Less support workload thanks to standardisation.
  • Reusable documentation for the IT team.
