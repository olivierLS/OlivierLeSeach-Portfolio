Case study

OffiTouch - Pharmagest

Preparing and installing a digital pharmacy window solution with a touchscreen display, Windows workstation, LGPI integration and remote maintenance.

  • Digital Systems vocational baccalaureate
  • OffiTouch
  • LGPI
  • Windows 10 Pro
  • MySQL / SQL
  • NEC P553
  • Lenovo ThinkCentre
  • Epson TM-30
  • Remote Desktop

Context and goals

Pharmacy need

OffiTouch is used in pharmacies to run an interactive window or sales-area display. The project required a reliable workstation able to drive the screen, connect with the LGPI environment and remain easy to administer after installation.

Key goals

  • Prepare a dedicated Windows workstation that is stable and maintainable.
  • Install the OffiTouch server, manager and display component.
  • Integrate the workflow with LGPI, ticket printing and backups.
  • Enable remote administration without making maintenance fragile.

Technical solutions

Interactive hardware

The display workstation used a Lenovo ThinkCentre mini-PC connected to an NEC MultiSync P553 touchscreen, with portrait orientation, DisplayPort input and touch calibration.

Windows preparation

The workstation was configured with a dedicated local account, automatic sign-in, suitable power settings, Remote Desktop access and a simplified interface to reduce interruptions.

OffiTouch services

The installation included the local server, SQL/MySQL database, manager, display component and backups to the LGPI shared space or to storage selected for the pharmacy.

LGPI and printing

The workflow accounted for the LGPI module/licence, Epson TM-30 printer and barcode ticket generation so the sale could be retrieved at the counter.

Main project stages

  1. 1. Analyse the requirement
    Identify the expected pharmacy setup: Screen, Wall or Stand, then check hardware, network and LGPI prerequisites.
  2. 2. Prepare the display workstation
    Install and configure Windows 10 Pro, the local account, automatic sign-in, always-on power settings and remote access.
  3. 3. Install OffiTouch
    Deploy the local server, manager and display module, then create the automatic startup shortcut.
  4. 4. Configure operations
    Set up backups, check LGPI rights, prepare remote administration and document useful access details.
  5. 5. Set up peripherals
    Configure the NEC touchscreen in portrait mode, calibrate touch input and install the Epson TM-30 printer when required.
  6. 6. Test and hand over
    Validate the manager, display and LGPI sale retrieval before finalising the maintenance documentation.

Testing and validation

Administration side

Connect to the workstation through Remote Desktop, open the OffiTouch manager, import a product by CIP code or name, then save the changes.

Display and counter side

Run a test sale from the display, print or show the customer code, retrieve the sale in LGPI and complete it at the counter.

Benefits and results

  • A more interactive pharmacy window for presenting products and guiding customers.
  • A dedicated workstation prepared to run continuously with fewer interruptions.
  • A smoother workflow between the display, LGPI and the pharmacy counter.
  • Easier maintenance through Remote Desktop, backups and documentation.
  • A useful learning experience in autonomy, technical discipline and professional teamwork.
