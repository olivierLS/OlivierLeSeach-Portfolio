Case study

GRR reservation server

Deploying an internal room and resource booking service for DSDEN.

  • GRR
  • WAMP
  • MySQL
  • Backups
  • GDPR

Context and goals

The administration needed an internal booking solution that could protect user information while remaining simple to access on the local network.

Technical solutions

Deploy GRR on a dedicated Windows 11 virtual machine.

Use WAMP and MySQL for the application and database layer.

Restrict network access and define a backup strategy for service continuity.

Main stages

  1. Prepare the virtual machine and service stack.
  2. Install and configure GRR, WAMP and MySQL.
  3. Secure access and limit exposed services.
  4. Validate bookings with users and IT staff.
  5. Document maintenance and restore procedures.

Benefits and results

  • Centralised reservation management.
  • Better control of access and exposed ports.
  • Backups supporting continuity of service.
  • A maintainable internal service for the team.
