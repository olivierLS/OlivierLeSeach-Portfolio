OffiTouch - Pharmagest

Preparación e instalación de una solución de escaparate digital para farmacia, con pantalla táctil, puesto Windows, integración con LGPI y mantenimiento remoto.

  • Epson TM-30
  • Escritorio remoto

Contexto y objetivos

Necesidad de la farmacia

OffiTouch se utiliza en farmacias para animar un escaparate o una zona de venta mediante una pantalla interactiva. El proyecto exigía preparar un puesto fiable, capaz de controlar la pantalla, comunicarse con el entorno LGPI y seguir siendo fácil de administrar después de la instalación.

Objetivos clave

  • Preparar un puesto Windows dedicado, estable y mantenible.
  • Instalar el servidor OffiTouch, el manager y el módulo de visualización.
  • Integrar el flujo con LGPI, la impresión de tickets y las copias de seguridad.
  • Permitir administración remota sin fragilizar el mantenimiento.

Soluciones técnicas

Hardware interactivo

El puesto de escaparate usaba un mini-PC Lenovo ThinkCentre conectado a una pantalla táctil NEC MultiSync P553, con orientación vertical, entrada DisplayPort y calibración táctil.

Preparación de Windows

El puesto se configuró con una cuenta local dedicada, inicio de sesión automático, ajustes de energía adecuados, acceso por escritorio remoto y una interfaz simplificada para limitar interrupciones.

Servicios OffiTouch

La instalación incluía el servidor local, la base SQL/MySQL, el manager, el módulo de visualización y las copias hacia el espacio compartido LGPI o el almacenamiento previsto por la farmacia.

LGPI e impresión

El flujo tenía en cuenta el módulo/licencia LGPI, la impresora Epson TM-30 y la generación de tickets con código de barras para recuperar después la venta en el mostrador.

Grandes etapas del proyecto

  1. 1. Analizar la necesidad
    Identificar el formato esperado en farmacia: Screen, Wall o Stand, y comprobar los requisitos de hardware, red y LGPI.
  2. 2. Preparar el puesto de escaparate
    Instalar y configurar Windows 10 Pro, la cuenta local, el inicio automático, la alimentación permanente y el acceso remoto.
  3. 3. Instalar OffiTouch
    Desplegar el servidor local, el manager y el módulo de visualización, y crear el acceso directo de arranque automático.
  4. 4. Configurar la explotación
    Definir copias de seguridad, comprobar derechos LGPI, preparar la administración remota y documentar los accesos útiles.
  5. 5. Instalar periféricos
    Ajustar la pantalla táctil NEC en modo vertical, calibrar el táctil e instalar la impresora Epson TM-30 si está prevista.
  6. 6. Probar y entregar
    Validar el manager, el escaparate y la recuperación de ventas en LGPI antes de finalizar la documentación de mantenimiento.

Pruebas y validación

Lado administración

Conexión al puesto por escritorio remoto, apertura del manager OffiTouch, importación de un producto por código CIP o por nombre, y guardado de los cambios.

Lado escaparate y mostrador

Realización de una venta de prueba desde la pantalla, impresión o visualización del código cliente, recuperación en LGPI y finalización de la venta en el mostrador.

Beneficios y resultados

  • Un escaparate más interactivo para presentar productos y orientar al cliente.
  • Un puesto dedicado, preparado para funcionar de forma continua con menos interrupciones.
  • Un flujo más fluido entre la pantalla, LGPI y el paso por mostrador.
  • Mantenimiento más sencillo gracias al escritorio remoto, las copias y la documentación.
  • Una experiencia útil en autonomía, rigor técnico y trabajo en entorno profesional.
