Caso práctico

Servidor de reservas GRR

Implantación de un servicio interno de reserva de salas y recursos para la DSDEN.

  • GRR
  • WAMP
  • MySQL
  • Copias
  • RGPD

Contexto y objetivos

La administración necesitaba una solución interna de reservas que protegiera los datos de los usuarios y siguiera siendo sencilla de usar en la red local.

Soluciones técnicas

Desplegar GRR en una máquina virtual Windows 11 dedicada.

Usar WAMP y MySQL para la aplicación y la base de datos.

Restringir el acceso de red y definir una estrategia de copias para la continuidad del servicio.

Etapas principales

  1. Preparar la máquina virtual y la pila de servicios.
  2. Instalar y configurar GRR, WAMP y MySQL.
  3. Proteger el acceso y limitar los servicios expuestos.
  4. Validar las reservas con usuarios y equipo informático.
  5. Documentar mantenimiento y restauración.

Beneficios y resultados

  • Gestión centralizada de reservas.
  • Mejor control de accesos y puertos expuestos.
  • Copias de seguridad para apoyar la continuidad.
  • Servicio interno mantenible por el equipo.
